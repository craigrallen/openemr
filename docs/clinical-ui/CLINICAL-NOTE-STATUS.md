The product change is a single guard replacement inside the complete native `FhirClinicalNotesService::parseOpenEMRRecord`: replace `if (!empty($dataRecord['activity'])) {` with `if (isset($dataRecord['activity'])) {`. Native `ClinicalNotesService` writes activity `0` for inactive notes, and both SELECT projections support stored integer `0` and string `"0"`. The original guard skipped these values and emitted `current`. The new guard maps them to `entered-in-error`, retains `current` for `1` and `"1"`, retains the fallback `current` for missing or null activity, and retains `entered-in-error` for nonzero `2` and `-1`. It also changes unsupported malformed `false` and empty-string values to `entered-in-error`; no preservation claim is made for every malformed value.

Its synthetic boundaries are `FhirServiceBase`, `FhirOrganizationService`, and `ClinicalNotesService` activity constants. It bypasses the mapper constructor and overrides only metadata and author population to avoid unrelated configuration and database access. Its row, organization reference, identifiers, text, date, and UTC timezone are synthetic. It does not load application bootstrap, vendor code, SQL, or a public request.

The fixture checks native getter and JSON status, fallback and nonzero cases, record order, native source provenance, unchanged nonstatus serialization, and unchanged input.
