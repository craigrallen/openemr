The portable Node contract runs the complete native inline script in a small jQuery and deferred-POST harness. It accepts the supplied original source or one exact anticipated source change. For the anticipated change, it removes only the specified inline-script replacement and hidden error container, then checks that the original SHA-256 is `453d6e9bd38462f4371e31568303da367acbd7e173f2fd2b54cdee5daa354532`. This checks the supplied source binding; it is not an independent HEAD, runtime, or repository attestation. A source or synthetic-boot mismatch exits 2 with a diagnostic, separately from behavioral failures, which produce one JSON report line and exit 1.

The intended behavior is to keep the recorded message hidden while POST is pending, prevent duplicate submissions, restore the session before POST, and reload after any successful HTTP 200 body. A failed POST shows a private, generic uncertainty alert. The request remains pending and its button hidden. “Check request status” restores the session and reloads the existing GET page without another POST. The GET page already distinguishes an open request from an available request button.

The exact proposed old and new script fragments and inserted markup are the `oldScript`, `candidateScript`, and `errorMarkup` constants in the portable contract. The later product change must match those literals for the exact inverse check to accept it. It preserves the original PHP, HTML, SQL, endpoint, ACL, CSRF expression, POST metadata, and original `#openreq` wording apart from that script replacement and container insertion.
