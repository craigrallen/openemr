# PractitionerRole specialty mapping

`PractitionerRoleService::search()` supplies `specialty_code` and `specialty_title` from the `facility_user_ids` specialty row joined to the `us-core-provider-specialty` list. `FhirPractitionerRoleService::parseOpenEMRRecord()` places that concept in `PractitionerRole.specialty`; the existing `role_code` and `role_title` concept remains in `PractitionerRole.code`. The change replaces one call to `addCode()` with `addSpecialty()` in the specialty block. Existing scalar coding and text construction and `empty()` guards remain as they were.

The tests-first commit is `1afdaf34b6a926ab219008d463176afa93dd56fa`. Before the production change, the controller reported 12 native contract cases: 9 passed and 3 failed. The failures were specialty-only code placement, a count of two role concepts when both values were present, and absent specialty in the independence case. The original mapper SHA-256 is `6bb2f8ce277c96e867ef30bf8c7b133fe4452a4efa49f52ff4d248cfd8ab3f04`; the fixture checks that reversing the single approved replacement restores that hash. Controller-added CLI guard and fixed static parent declaration comments in the test fixture are nonproduction exceptions to the one-block production change.

The fixture checks native PractitionerRole and CodeableConcept objects and encoded JSON, including role-only, specialty-only, both, missing and empty values, independent concepts, and unchanged references, telecom, and metadata. Its seam uses a fixed synthetic parent declaration and Reflection to instantiate the native mapper without its application constructor; it does not exercise application bootstrap. The existing CodeableConcept PHPDoc names FHIRCoding and FHIRString, while the mapper passes scalar code and text values accepted by these runtime methods. These contract checks do not establish full FHIR conformance, inbound behavior, authenticated SQL behavior, clinical UI acceptance, independent review, or CI success. This is supporting interoperability work, not full original22 or researched UI delivery.
