# Fax patient popup presentation (OPEMR-185)

This implementation gives the existing fax patient popup a paper-like workbench presentation when the workbench context is active. It is a partial, source-researched presentation change. It does not establish clinical, security, or workflow acceptance.

## Actual route and launch

The standalone route is `interface/modules/custom_modules/oe-module-faxsms/library/utility.php`. `createPatient()` in `interface/modules/custom_modules/oe-module-faxsms/public/js/messageUI.js` launches it through `dlgopen` with `modal-md`, a `full` height argument, and `sizeHeight: 'full'`. The route retains its original form, checkbox, Existing Patient and Confirm New Patient buttons, PHP behavior, and JavaScript callbacks.

The added body class activates its inline CSS only under `html.oe-workbench-context` and `@media screen`. The CSS uses workbench token values with physical fallbacks for a centered, bounded sheet, form width, spacing, focus outlines, and an action row. It leaves native button and checkbox semantic colors to the existing theme. The repo declares Bootstrap 4.6.2 and its theme imports Bootstrap Sass. The controller verified `.float-right { float: right !important; }` in the existing compiled dark-theme fixture, so the action row has one narrowly scoped `float: none !important` override; there are no other important declarations in this proposal. The small-screen rule uses `(width <= 600px)`.
