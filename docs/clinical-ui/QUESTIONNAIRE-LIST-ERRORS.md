# OPEMR-227 Questionnaire list errors

The public `list()` route returns the response produced by `getAll()` directly. On an error, `getAll()` passes the native `ProcessingResult` and success-code argument `200` to `RestControllerHelper::handleFhirProcessingResult()` before reading data or building entries. That helper returns a Symfony HttpFoundation `Response`, while the controller requires a PSR `ResponseInterface`. The error branch converts the exact helper response with `PsrHttpFactory`. Its four constructor arguments come, in order, from `OpenEMR\BC\ServiceContainer::getServerRequestFactory()`, `getResponseFactory()`, `getStreamFactory()`, and `getUploadedFileFactory()`. The container resolves these by separate interfaces, so the arguments need not be the same object. Healthy searches still build a Questionnaire Bundle and serialize it once, including an empty Bundle when the service has no errors and no data.
