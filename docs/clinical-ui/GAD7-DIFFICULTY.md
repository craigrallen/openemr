# GAD-7 difficulty change handler

The native GAD-7 script assigned a string to the dynamically created difficulty menu's `onchange` property. In Chromium that property was not a callable handler, so a difficulty selection did not call `record_score_q8` or set `changes_made`. The replacement assigns a function that reads the changed menu's value. It leaves scoring, defaults, and `Number('undef')` behavior intact.

`new.php` and `view.php` both load `gad7_javasrc.js` and create the optional menu through `manage_question_8` when the first seven answers yield a positive score. Both Cancel paths call `nosave_exit`, which uses `changes_made` to decide whether to confirm. The new-form Cancel path first calls `check_all(false)`, which can also set that flag when a scored answer is present; the edit-form Cancel path calls `nosave_exit` directly. The handler makes a difficulty change itself mark the form dirty. In `save.php`, the new path passes raw `$_POST` to `formSubmit`, while the update path reads `$_POST['difficulty']` into its SQL parameters. This change does not modify either save path.

Tests were established on immutable HEAD `91277c982e8be3abe1dbb8df699751269552fa0d` before the product edit. The controller's portable source-derived contract RED result was 7 failing checks among 11; its real Chromium RED result on the source-rendered native new template showed `false !== true` for the dirty flag after selecting difficulty `0`. The portable test evaluates the complete native JS in a synthetic DOM. The controller browser test uses real Chromium and source-rendered native new/edit template bodies with synthetic strings, record, CSRF, and session restore. Neither test boots PHP or the application, follows authenticated Cancel navigation, submits Save, or checks database persistence. These results do not establish data loss, security, clinical, or full-form acceptance.

The change remains a draft, unmerged, and undeployed. Ordinary approval and full exact-HEAD hosted gates remain pending; the controller owns independent review and browser verification.
