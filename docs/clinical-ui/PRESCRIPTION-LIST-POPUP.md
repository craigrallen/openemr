# OPEMR-177: native prescription list popup

## Scope and launcher proof

This change gives the native prescription list a restrained paper document inside an active workbench popup. The researched UI in `/Users/craig/artifacts/OpenEMR-Research/researched/index.html` supplies a partial visual direction: light paper, quiet borders, dark ink, and contained tables. It is a synthetic, mock-only proposal, not a full reference for the prescription list or evidence of clinical behavior.

The EyeMag `editScripts` caller in `interface/forms/eye_mag/js/eye_base.php` navigates its `editScripts` iframe to `controller.php?prescription&list&` with the patient id and opens `dlgopen` at width 910 and height 400 with resizing enabled. The demographics caller in `interface/patient_file/summary/demographics.php` opens the same list URL through `editScripts` at `modal-xl` and height 400, with resizing enabled, when `erx_enable` is false. With eRx enabled, demographics links to the eRx compose page instead. `C_Prescription::list_action` gets the prescription rows and configuration flags, then renders `prescription/` plus its `template_mod` plus `_list.html.twig`; the general template is the target here. `Header::setupHeader` loads the normal assets, while `popup.js` marks the active workbench context on `<html>` and `popup.css` supplies the shared popup styling.

The added `@media screen` rules require both `html.oe-workbench-context` and `body.oe-prescription-list-document`. They cap the existing container at 1100px, wrap the existing action groups, keep the original table inside its scroll container at a minimum width of 64rem, and pair table and hover text with light backgrounds. No wrapper, asset, action, controller, or print rule was added. The contract's inverse comparison against the whole original fixture is the pending gate for exact preservation of the original Twig, JavaScript, markup, identifiers, routes, and conditionals. The two-seam diff leaves the inherited duplicate IDs and email Cancel event bug in place; neither is part of this presentation change.
