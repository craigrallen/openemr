# OPEMR-231: Telehealth session modal names

The two modal roots in `interface/modules/custom_modules/oe-module-comlink-telehealth/templates/comlink/conference-room.twig` need accessible names. The approved production change adds `aria-label="{{ "Confirm Session Close" | xla }}"` to `telehealth-container-hangup-confirm` and `aria-label="{{ "Configure Session" | xla }}"` to `telehealth-container-configure-session`. Their visible headings continue to use `xlt`. No role, ID, behavior, style, include, appointment status, save, or CSRF change is in scope.

The controller copies the original Twig source byte for byte to `tests/clinical-ui/fixtures/telehealth-session-modals-original.twig.txt` before the production edit. Its expected SHA-256 is `c5138e143268c38fea282e976ab86017a16fbecc8c290a28f743df42859a46e0`. The dependency-free Node contract checks that fixture, the actual Twig source, the two exact root tags and labels, and byte identity after reversing only the approved additions. Mutation cases cover missing, duplicate, misplaced, swapped, and incorrectly escaped labels, unrelated appointment status and checkbox drift, and fixture tampering. The Jest adapter checks the contract report and process result.

The native callers select the existing roots with `document.getElementById` and construct `bootstrap.Modal` on them. They do not clone the roots; an earlier issue description claiming cloning was incorrect.

TDD and hosted Jest acceptance await controller materialization and outputs. These checks inspect source text; they do not establish rendered Twig behavior, Bootstrap operation, screen reader announcements, roles, security, video behavior, or clinical acceptance.
