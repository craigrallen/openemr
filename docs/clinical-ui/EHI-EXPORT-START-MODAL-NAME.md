# EHI export start dialog accessible name

This change adds an `xla` translated `aria-label` to the root of the export start modal. The visible `h5` retains its `xlt` text. The source contract pins the complete original template and accepts only the specified opening-tag addition, so it also checks preservation of the caller, close label, CSRF token, and `createExport` form action.

Support is source-only. Genuine RED and GREEN results await controller capture; no results are asserted here. No application, Twig, export, SQL, browser, or local Jest execution was performed in this phase.

Native authenticated assistive technology and keyboard QA must check the accessible name, focus, and roles. Export persistence QA, ordinary approval, and CI remain open. This is not runtime, export, clinical, security, or accessibility acceptance. No merge or deploy is authorized by this document. Researched visual fidelity, all22, demo, and Swedish acceptance are outside this scope.
