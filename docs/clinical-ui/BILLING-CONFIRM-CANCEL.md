# Billing confirmation Cancel binding

The source change binds `doConfirm` to the generated Cancel button’s `btn-cancel` class. The button is `type='button'`, uses `btn-secondary`, and has `data-dismiss='modal'`. The prior `btn-danger` selector matches no generated Cancel button. On a Cancel click, the handler calls `off()` and rejects with `btn-cancel`; the existing `confirmActions` catch logs a warning. Continue, Validate Only, and Validate and Clear retain their existing resolve handlers and submission path. The modal’s `hidden.bs.modal` handler removes it.
