# Fee Sheet help in the workbench

## Scope and source path

This is a bounded source adaptation of the existing Fee Sheet help page toward the researched clinical UI palette. It is not a full redesign, completion of the 22-feature acceptance register, or acceptance of every popup. The only route change is a body marker and five screen-only paint rules in `Documentation/help_files/fee_sheet_help.php`. The original 21,763 bytes remain recoverable by removing those two additions. The original 768px responsive rule, seven sections, translated text, buttons, warnings, links and spreadsheet download remain in place.

The real caller is `interface/forms/fee_sheet/new.php`: it passes `show_help_icon => true` and `help_file_name => "fee_sheet_help.php"` to `OemrUI`, renders the heading, then calls `oeBelowContainerDiv()`. In `src/OeUI/OemrUI.php`, the constructor registers the help-icon listener only when `enable_help !== 0` and `display_help_icon` is truthy; `oeBelowContainerDiv()` constructs the modal based only on `display_help_icon`. The ordinary Bootstrap `#myModal` contains `#targetiframe` with an empty `src` and the help path in `data-src`; the delegated `#help-href` click fills `src` once. Actual usable availability still depends on the existing authenticated session, role/configuration, and help eligibility. This work does not change those checks.

`interface/clinical-workspace/popup.js` follows a same-origin parent chain to an active workbench shell and marks the help document's `<html>` with `oe-workbench-context`. The ordinary help iframe is not a `.dialogModal` frame created by `dlgopen`; it gets context without the `oe-workbench-popup` class. The new rules require both that context and the route-specific body marker. They pair canvas/ink and paper/ink colors for the body and sheet, then pair heading and non-button link colors. Two `!important` declarations counter the existing help theme's heading background and redirect-link color. No typography, geometry, spacing, script, control behavior, or semantic warning color was changed.

The new CSS is inside `@media screen`; its body marker remains in the DOM for all media. The original print source is preserved, but native print equivalence has not been checked. The shared popup sheet's backdrop can still affect contrast around unchanged semantic warnings. Existing responsive geometry remains as before; preserving it is not evidence of accessibility at narrow or short viewports.
