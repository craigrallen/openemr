# CouchDB log popup source contract

This tests-only slice freezes the original `interface/couchdb/couchdb_log.php` and `ClinicalWorkspaceAssets.php` bytes in dedicated fixtures. The Node source guards require complete equality with one explicit proposed transformation. They also pin the existing caller and `popup.js`, exercise a passing synthetic candidate, reverse only the declared route additions to recover the exact original bytes, and reject anchored mutations, including a deleted local ACL block and filename lookup moved before the ACL.

The proposed route checks `admin/users` immediately after its imports and uses the terminating `AccessDeniedHelper::denyWithTemplate` path before a filename lookup, filesystem read, decryption, or HTML. It keeps the existing missing-file exit, empty translations, `text()` escaping, and `nl2br()`. The only added markup is a valid document head and the `oe-couchdb-log` body, sheet, and content wrappers. The head versions only local `couchdb-log-popup.css` and the existing `popup.js` through `ClinicalWorkspaceAssets`, with escaped webroot and URL values. The CSS is screen-only and requires `html.oe-workbench-context`; its proposed indentation is 2 spaces for selectors and 4 for declarations. The existing popup engine obtains that class from its host. A standalone route with no workbench host does not receive the new CSS.

These source checks do **not** prove actual PHP parsing or bootstrap, filesystem or cryptography behaviour, ACL authority, rendered theme, keyboard use, narrow screens, RTL, print output, or role behaviour. Ordinary review and CI, plus native acceptance, remain pending. This slice does not merge or deploy anything.
