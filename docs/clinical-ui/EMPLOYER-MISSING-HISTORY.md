# OPEMR-128: employer save with no prior history

The demographics save path calls `updateEmployerData($pid, ..., false, $patientData)` in `interface/patient_file/summary/demographics_save.php`, through the wrapper in `library/patient.inc.php`, into `EmployerService::updateEmployerData()`. The demographics page reads the latest employer through that same wrapper and `getMostRecentEmployerData()`. When there is no employer row, the native read returns `false`. Iterating it discarded the prepared submitted fields and skipped the insert. The service now merges old fields only when the read returns an array, retaining the prepared new fields for `false`. An array result, including an empty array, keeps its prior behavior. The existing server-set patient and creator IDs, patient occupation and industry, date replacement, fresh UUID, metadata-based column filtering, and insert path remain in place.

The committed isolated regression file is `tests/Tests/Isolated/Services/EmployerMissingHistoryTest.php` at `b5fb7c54`. It uses the native employer and base service methods with synthetic session and UUID values; only the QueryUtils database boundary is recorded. No database, authenticated session, or live endpoint is exercised. Before this service change, the controller's PHP 8.5 native RED run reported **5 tests, 41 assertions, 2 failures**: both missing-history saves returned `''` instead of the mocked insert ID `314`, with a native `foreach(false)` warning. The three characterization tests passed. Earlier loader setup failures were separate from this product RED.

Test selection: `tests/Tests/Isolated/Services/EmployerMissingHistoryTest.php` with `-c phpunit-isolated.xml`, using `PHPUNIT_COMPOSER_INSTALL` set to the controller's external native bootstrap. The handoff did not retain the exact executable and bootstrap paths, so an exact replay command cannot be stated here. The loader is external to this checkout; no target `vendor` install is implied. This implementation phase did not run PHP or tests, so GREEN remains pending controller verification.
