# EOB invoice popup: Invoice Actions palette slice

Status: production source edited on `OPEMR-41-eob-invoice-actions-sheet`; hosted GREEN and native acceptance remain pending.

`interface/billing/sl_eob_invoice.php` loads a screen-only, escaped-webroot, per-file-versioned stylesheet after `Header::setupHeader`. A class on the first fieldset scopes it to Invoice Actions; Invoice Details stays outside that class. The three CSS rules give the fieldset, its direct legend, and its `bg-light` Insurance card paired workbench ink and paper colors only when `html` has `oe-workbench-context`. The fieldset and legend need `!important` to override paired theme rules, and the card needs it to override the theme utility. Existing native controls keep their own theme palettes. This is a partial Invoice Actions body and Insurance card palette change, not whole-popup or researched-fidelity acceptance. The route, form behavior, geometry, typography, focus, shared runtime, and launcher are otherwise outside this slice.

The genuine hosted tests-only RED at `ef31e65e6b61cda0b2a1396eeaeecafaf650448a` was JS Unit Test `39140171430`: 1,264 passed across 62 suites, with exactly three intended failures for the absent route additions, supported asset entry, and stylesheet. Synthetic positive, mutation, and launcher oracles passed before production. The frozen full-route fixture and test bytes remain unchanged. Hosted GREEN, syntax and exact-source inverse checks, CSS lint, independent review, and native UI checks have not yet been reported for this production edit.

The actual route requires `acct/eob` write ACL. It checks CSRF locally for `form_save` POST only; its `isLastClosed` and `enc_billing_note` write branches have no local CSRF check. The GET posting path calls `prevSetting`, which can mutate preferences. Exact source preservation of these paths is not a security clearance. Native compiled-theme contrast, including descendants affected by ancestor repaint, and legacy and print behavior remain acceptance gates. No live application request or financial action was made for this slice.
